Artikel in gemeinsamer Datenbank

Publikation via GitHub & Vercel

So veröffentlichst du deine App dauerhaft unter einer eigenen Vercel-URL mit Echtzeit-Cloud-Datenbank für alle Benutzer:

1. Dateien im GitHub-Repository

Erstelle ein neues GitHub-Repository und lege diese Datei als index.html sowie optional folgende vercel.json ab:

{ "version": 2, "cleanUrls": true, "trailingSlash": false }
2. Firebase Firestore für eigenes Vercel-Hosting verbinden

In dieser Vorschau-Umgebung ist die Cloud-Datenbank bereits automatisch verbunden. Für deine eigene Vercel-Domain kannst du in der Firebase Console (kostenloser Spark-Plan) ein Projekt anlegen, Firestore aktivieren + Anonyme Authentifizierung einschalten und dein Konfigurationsobjekt direkt in window.CUSTOM_FIREBASE_CONFIG in der index.html eintragen.

rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /artifacts/{appId}/public/data/{collection}/{docId} { allow read, write: if request.auth != null; } } }
